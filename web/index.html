Gateway setup

Install the firmware on a LilyGo T-SIM7000G board and choose the WiFi name and password your devices will join. No software to install.

This page needs Chrome or Edge on a computer (Windows, Mac or Linux). It does not work in Firefox, Safari or on phones.

1 Install the firmware

Fit the SIM card and antenna, plug the board into this computer with a USB cable, then click Install and pick the board in the list. This erases the board and takes about a minute.

This page must be opened over https.

When it says the installation is complete, close that window and go to step 2. Skip this step if the board already has the firmware.

2 Set up the hotspot

Click Connect and pick the board in the list again.

APN username and password (most SIM cards don't need these)

3 Check it works

Connect to the board in step 2 to see its status here.

When the board is online, its LED stays on. Then check that a phone can see and join your WiFi name. Connecting to the mobile network can take a few minutes.

Problems?

  • The board isn't in the list: try another USB cable (some only charge). On Windows the board may need a USB driver: install the CH343 driver (newer boards) or the CP210x driver (older boards), then unplug and replug the board.
  • "Can't open the board": close the install window, other browser tabs using the board, and any serial monitor, then try again.
  • The board doesn't answer: press the RST button on the board and click Connect again.
  • Mobile data stays "connecting": check the APN with your SIM provider, that the antenna is attached, and that the SIM has mobile data enabled and no PIN.
